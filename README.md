# Sprout

Приложение против прокрастинации для Android. Локальное, без аккаунтов и без интернета.

Прокрастинация — это не про тайм-менеджмент, а про эмоциональную регуляцию: мы откладываем не потому, что не умеем планировать, а потому что задача вызывает тревогу, скуку или стыд. Таймер лечит симптом. Sprout работает с моментом избегания — с тем самым, когда рука сама тянется к телефону.

## Что внутри

| | |
|---|---|
| **Одна задача на экране** | Список живёт на своей вкладке. У задачи обязателен первый шаг — настолько маленький, чтобы отказаться было неловко |
| **«Не могу начать»** | Шесть причин, и каждая ведёт к действию, а не к совету. Кнопка на виду: ей должно быть не стыдно воспользоваться |
| **План «если — то»** | Самый сильный доказанный приём против откладывания (d = 0.65). В назначенное время приходит уведомление с кнопкой «Начать» — сессия заводится, не открывая приложение |
| **Таймер** | 15/20/25/45 минут и «Поток». Переживает перезагрузку: в базе хранится момент старта, а не тикающий счётчик |
| **Растение и серия** | Растёт от минут фокуса. Пропуск дня **не убивает** растение |
| **Меньше отвлечений** | Мягкий барьер поверх выбранных приложений во время сессии и «не беспокоить» на время работы. Барьер можно пройти всегда — он нужен, чтобы это перестало происходить на автопилоте |
| **Экран «Я»** | Не дашборд, а наблюдения: что тебя останавливает чаще всего, как длина захода связана с доводимостью. Графиков нет намеренно — на плохой неделе график превращается в счёт к самой себе |
| **Эксперименты над собой** | Приложение выбирает гипотезу из твоих слабых мест, неделю само ведёт себя иначе и считает результат. Условие соблюдает приложение, а не человек: «ты сегодня выполнила?» — это ещё одно требование к тому, кто и так не справляется |

## Данные

Всё живёт на телефоне, в базе внутри приложения. Ни аккаунтов, ни сервера, ни аналитики: список задач и причин избегания — довольно личные вещи, и они никуда не отправляются. Обратная сторона честная: **резервной копии нет**. Удалишь приложение — данные уйдут вместе с ним.

Разрешения приложение просит по одному и только когда они нужны:

| Разрешение | Зачем | Что приложение **не** делает |
|---|---|---|
| Уведомления | Отсчёт в шторке, сигнал об окончании, напоминания по плану | — |
| Точные будильники | Сессия и напоминание срабатывают вовремя, а не «в течение 15 минут» | — |
| Доступ к статистике приложений | Узнать, что открыто поверх Sprout во время сессии | Не читает содержимое чужих экранов: для этого нужна служба специальных возможностей, и Sprout её не просит |
| Рисовать поверх приложений | Показать барьер | — |
| Доступ к режиму «не беспокоить» | Включить тишину на время сессии и снять её после | Не глушит наглухо: звонки от избранных и повторные проходят по правилам, которые уже настроены в системе |

Барьер и тишина по умолчанию выключены.

## Установка

APK лежит в разделе [Releases](../../releases). Android спросит подтверждение — это обычное дело для приложения не из Play: «Настройки → разрешить установку из этого источника».

Нужен Android 8 или новее.

## Сборка из исходников

```powershell
$env:JAVA_HOME = "путь\к\jdk21"
.\gradlew.bat assembleDebug
```

JDK 21, Android SDK 37. Подпись выпуска берётся из `keystore.properties` в корне — без него собирается только отладочная версия.

```powershell
.\gradlew.bat testDebugUnitTest          # расчёт и формулировки
.\gradlew.bat connectedDebugAndroidTest  # миграции базы и сквозной путь
```

⚠️ Второй прогон **удаляет приложение с устройства вместе с данными**. Только на эмуляторе.

## Как это сделано

Написано на Kotlin и Compose, база — Room. Ни одного экрана «настройки по умолчанию»: тон, пороги и формулировки — часть замысла, а не оформление. Подробности решений — в комментариях к коду, они там на русском и объясняют «почему», а не «что».
